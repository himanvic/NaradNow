# Changelog

- Added UPSC/CSE and SSC/General Awareness study mode with suggested topic buckets, study angles, and locally stored revision markers.
- Added saved-story export to a plain-text file and support for loading additional story pages when the provider returns a continuation token.
- Expanded the current-affairs quiz to five questions using loaded headlines and source/topic metadata.
- Kept filtering and de-duplication in the main story grid and news ticker.
- Removed technical connection/status panels from the reader-facing homepage and replaced setup-style notices with reader-friendly messages.
- Added project repository and developer attribution links to the footer.
- Updated public-facing copy, documentation, and offline cache version.
- Preserved the existing Cloudflare Worker URL and expected `NEWS_DATA_API_KEY` secret name.
